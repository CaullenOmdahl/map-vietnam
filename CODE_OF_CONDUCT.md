# Code of conduct

This project deals with a war and with the people who died in it. Contributors come to it from
different countries and different sides of that history.

- Be civil. Disagree about the evidence, not about the person.
- Treat every record as someone's relative. No jokes, no slurs, no point-scoring about the dead
  of any side.
- Don't post personal details about living people.
- Keep politics out of issues and pull requests unless a record's accuracy depends on it.

If someone's behaviour is a problem, contact the repository owner through their GitHub profile.
Maintainers may edit or remove comments, and may block people who keep at it.
