# Security

Map Vietnam runs on your own computer and listens on `127.0.0.1` only. It has no log-in, so it
should never be exposed to a network.

## Reporting a problem

Please don't open a public issue for a security problem. Use **Report a vulnerability** under the
repository's **Security** tab on GitHub, which sends a private report to the maintainers. Say
what you did, what happened and what you expected, and include the version or commit.

You should hear back within a week.

## What counts

- Anything that lets a web page or another machine read or change your cases, notes or files
  through the local server
- Anything that makes Map Vietnam download or run something you didn't ask for
- A leaked key or personal detail in the repository

A wrong record or a misplaced map is not a security problem. Open an ordinary issue for those.
